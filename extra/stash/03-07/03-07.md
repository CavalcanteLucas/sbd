# 03-07

Considere a consulta SQL

<pre>
    <b>select</b> p.a1
    <b>from</b> p, r1, r2
    <b>where</b> p.a1 = r1.a1 <b>or</b> p.a1 = r2.a1
</pre>

Sob quais condições essa consulta seleciona valores de $p.a1$ que estão em $r1$ ou em $r2$? Examine, cuidadosamente, os casos em que ou $r1$ ou $r2$ pode ser vazio.

## Resposta

Essa consulta equivale ao produto cartesiano $p \times r1 \times r2$. Seu resultado contém cada item de $p.a1$ que possui correspondente em $r1.a1$ ou em $r2.a2$, contanto que nem $r1$ nem $r2$ sejam vazios.

Vejamos um exemplo, utilizando a instância de banco implementada no arquivo `03-07-1.sql`.

```
misc.p   misc.r1  misc.r2

| a1 |   | a1 |   | a1 |
| -- |   | -- |     --
| x  |   | x  |   | y  |
| x  |   | y  |   | z  |
| y  |   | y  |
| z  |
| w  |
```

Vamos analizar o produto cartesiano entre essas relações considerado cada valor distinto de $p.a1$:

- Para o valor `x`, temos:

| p.a1  | r1.a1 | r2.a1 |
| -- | -- | -- |
| **x**  | **x**  | **y**  |
| **x**  | **x**  | **z**  |
| x  | y  | y  |
| x  | y  | z  |
| x  | y  | y  |
| x  | y  | z  |
| **x**  | **x**  | **y**  |
| **x**  | **x**  | **z**  |
| x  | y  | y  |
| x  | y  | z  |
| x  | y  | y  |
| x  | y  | z  |


- Para o valor `y`, temos:

| p.a1  | r1.a1 | r2.a1 |
| -- | -- | -- |
| **y**  | **x**  | **y**  |
| y  | x  | z  |
| **y**  | **y**  | **y**  |
| **y**  | **y**  | **z**  |
| **y**  | **y**  | **y**  |
| **y**  | **y**  | **z**  |


- Para o valor `z`, temos:

| p.a1  | r1.a1 | r2.a1 |
| -- | -- | -- |
| z  | x  | y  |
| **z**  | **x**  | **z**  |
| z  | y  | y  |
| **z**  | **y**  | **z**  |
| z  | y  | y  |
| **z**  | **y**  | **z**  |

- O valor `w` não possui correspondências em `r1.a1` nem em `r2.a1`, portanto o resultado é vazio.

O resultado da consulta exibe apenas os valores da coluna `p.a1`, portanto temos:

```sql 03-07-02.sql
select
  misc.p.a1
from
  misc.p,
  misc.r1,
  misc.r2
where
  misc.p.a1 = misc.r1.a1
  or misc.p.a1 = misc.r2.a1;
```
| a1 |
| -- |
| x  |
| x  |
| x  |
| x  |
| y  |
| y  |
| y  |
| y  |
| y  |
| z  |
| z  |
| z  |

Agora, caso $r2$ (ou em $r1$) seja vazio, o resultado seria $p \times r1 \times \varnothing = \varnothing$. 

Para verificar, remova todos os valores da tabela `r2`:
```sql 03-07-3.sql
delete from misc.r2;
```

e execute a mesma consulta [`03-07-02.sql`] novamente.
