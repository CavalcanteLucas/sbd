# 03-10

Considere o banco de dados relacional da Figura 3.19. Dê uma expressão em SQL para cada uma das seguintes tarefas.

**a)** Modifique o banco de dados para que o fato de que o empregado cuja ID é '12345' agora mora em "Newtown".

**b)** Dê a todos os gerentes da "First Bank Corporation" um aumento de 10%, a menos que o salário se torne maior que $100.000; nesses casos, considere apenas um aumento de 5%.

<pre>
    empregado(<u>ID</u>, nome_empregado, rua, cidade)
    trabalha(<u>ID</u>, nome_empresa, salário)
    empresa(<u>nome_empresa</u>, cidade)
    gerencia(<u>ID</u>, id_gerente)
</pre>

**Figura 3.19** - Banco de dados de empregado.

## Resposta

As consultas de atualização necessárias para reponder essa questão modificam o estado do banco. Por isso, é importante verificar o estado dos dados antes de executar as consultas a seguir.

### a)

Vejamos qual a cidade desse empregado antes da atualização:

```sql 03-10-a1.sql
select
    cidade
from
    empregado.empregado
where
    id like '12345';
```
| cidade  |
| ------- |
| Belo Jardim |

Agora, vamos realizar a atualização:

```sql 03-10-a2.sql
update empregado.empregado
set
    cidade = 'Newtown'
where
    id = '12345';
```

Execute a primeira consulta [`03-10-a1.sql`] novamente para verificar a cidade desse empregado após a atualização:

```sql 03-10-a1.sql
select
    cidade
from
    empregado.empregado
where
    id like '12345';
```
| cidade  |
| ------- |
| Newtown |

### b)

Vejamos o salário dos gerentes dessa empresa antes da atualização:

```sql 03-10-b1.sql
select distinct
    g.id_gerente,
    t.salario
from
    empregado.gerencia g,
    empregado.trabalha t
where
    g.id_gerente = t.id
    and lower(t.nome_empresa) like '%first bank%';
```
| id_gerente | salario  |
| ---------- | -------- |
| 12345      | 9000.00  |
| 39991      | 11200.00 |
| 39993      | 9400.00  |

Agora, vamos realizar a atualização:

```sql 03-10-b2.sql
update empregado.trabalha
set
    salario = case
        when salario * 1.1 > 10000 then salario * 1.03
        else salario * 1.1
    end
where
    lower(nome_empresa) like '%first bank%'
    and id in (
        select distinct
            id_gerente
        from
            empregado.gerencia
    );
```

Execute a primeira consulta [`03-10-b1.sql`] novamente para verificar o novo salário desses gerentes:

```sql 03-10-b1.sql
select distinct
    g.id_gerente,
    t.salario
from
    empregado.gerencia g,
    empregado.trabalha t
where
    g.id_gerente = t.id
    and lower(t.nome_empresa) like '%first bank%';
```
| id_gerente | salario  |
| ---------- | -------- |
| 12345      | 9900.00  |
| 39991      | 11536.00 |
| 39993      | 9682.00  |

Nesse exemplo, apenas o gerente com id '12345' ganhou um aumento de 10%. Todos os demais ganharam 3%, incluindo o trabalhador com id '39993', que ficaria com um salário superior a $10.000. Qualquer outro gerente já ganhava mais de $10.000 mesmo antes do aumento.
