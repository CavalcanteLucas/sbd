# 02-15

Considere o banco de dados da agência bancária da Figura 2.18. Dê uma expressão na álgebra relacional para cad uma das seguintes consultas:

<sub>**Figura 2.18** - Banco de dados de agência bancária.</sub>
<pre>
    agência(<ins>nome_agência</ins>, cidade_agência, ativos)
    cliente(<ins>ID</ins>, nome_cliente, endereço_cliente, cidade_cliente)
    empréstimo(<ins>número_empréstimo</ins>, <ins>nome_agência</ins>, valor)
    tomador(<ins>ID</ins>, <ins>número_empréstimo</ins>)
    conta(<ins>número_conta</ins>, <ins>nome_agência</ins>, saldo)
    depositante(<ins>ID</ins>, <ins>número_conta</ins>)
</pre>

**a)** Ache todos os números de empréstimo com valor superior a $10.000.

**b)** Ache a ID de todos os depositantess que têm conta com saldo maior que $6.000.

**c)** Ache a ID de todos os depositantes que têm conta com saldo maior que $6.000 na agência "Uptown".

## Resposta

### a)

```math
\begin{align*}
&\prod\nolimits_{número\_empréstimo}(\sigma_{valor\gt 10.000}(empréstimo))
\end{align*}
```

### b)

```math
\begin{align*}
&\prod\nolimits_{ID}(\sigma_{saldo\gt 6.000}(depositante \bowtie_{número\_sala} conta))
\end{align*}
```

### c)

```math
\begin{align*}
&\prod\nolimits_{ID}( \\
&\qquad\sigma_{saldo \gt 6.000}( \\
&\qquad\qquad depositante \\
&\qquad\qquad \bowtie_{número\_conta} (conta) \\
&\qquad\qquad \bowtie_{número\_agência} (agência)\\
&\qquad) \\
&)
\end{align*}
```
