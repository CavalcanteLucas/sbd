    carro(<ins>renavam</ins>, modelo, ano)

**a)** Ache o número total de pessoas que possuíram carros e estiveram envolvidas em acidentes em 2017.

**b)** Exclua todos os carros do ano de 2010 pertencentes à pessoa cuja ID é `12345`.

## Resposta

Para preparar o banco de dados de seguro da [Figura 3.17](#Figura-3.17), utilize as instruções a seguir ([03-04-0.sql](../lab/dbt_/macros/chap-03/03-04/03-04-0.sql)):

```sql
create schema seguro

create table seguro.pessoa (
    id_motorista varchar(10) primary key,
    nome varchar(10),
    endereco varchar(10)
)

create table seguro.carro (
    renavam varchar(10) primary key,
    modelo varchar(10),
    ano varchar(4)
)

create table seguro.acidente (
    num_sinistro varchar(10) primary key,
    ano int,
    local varchar(10)
)

create table seguro.possui (
    id_motorista varchar(10),
    renavam varchar(10),
    primary key (id_motorista, renavam),
    foreign key (renavam) references seguro.carro(renavam) on delete cascade,
    foreign key (id_motorista) references seguro.pessoa(id_motorista) on delete cascade
)

create table seguro.participou (
    num_sinistro varchar(10),
    renavam varchar(10),
    id_motorista varchar(10),
    valor_dano decimal(6, 2),
    primary key (id_motorista, renavam),
    foreign key (renavam) references seguro.carro(renavam) on delete cascade,
    foreign key (id_motorista) references seguro.pessoa(id_motorista) on delete cascade
);

insert into seguro.pessoa (id_motorista, nome, endereco) values
('11111', 'Lucas', 'Rua A'),
('11112', 'Maria', 'Rua B'),
('11113', 'Carla', 'Rua C'),
('12345', 'Pedro', 'Rua D'),
('22222', 'Pedro', 'Rua E');

insert into seguro.carro (renavam, modelo, ano) values

('R002', 'Onix', '2010'),
('R003', 'Palio', '2011'),
('R004', 'Corsa', '2010');

insert into seguro.acidente (num_sinistro, ano, local) values

('S002', 2016, 'BairroA'),

insert into seguro.possui (id_motorista, renavam) values
('11111', 'R001'),
('11111', 'R002'),

('S001', 'R002', '11112', 2200.00),
('S002', 'R003', '11113', 5000.00),
('S003', 'R001', '12345', 300.00),
('S003', 'R002', '22222', 950.00),
('S004', 'R003', '11111', 300.00),

```

### a)

Aqui, precisamos considerar pessoas com vários acidentes apenas uma vez. Por isso, precisamos da cláusula `DISTINCT`. Além disso, precisamos considerar o dono do carro envolvido no acidente, e não o condutor que participou no acidente. Por isso, precisamos obter o `renavam` do carro envolvido no acidente para encontrar seu dono. Juntando tudo isso, temos ([03-04-a.sql](../lab/dbt_/models/chap-03/03-04/03-04-a.sql)):

```sql
select
  count(distinct po.id_motorista)
from
  seguro.possui as po,
  seguro.participou as pa,
  seguro.acidente as ac
where
  (
    ac.ano = 2017
    and ac.num_sinistro = pa.num_sinistro
    and pa.renavam = po.renavam
  );
```
| count |
| ----- |
| 3     |

### b)

Antes de modificar o banco, lembre-se de verificar o estado estado atual das tabelas possivelmente afetadas (veja as consultas [03-04-b1-i.sql](../lab/dbt_/models/chap-03/03-04/03-04-b1-i.sql), [03-04-b1-ii.sql](../lab/dbt_/models/chap-03/03-04/03-04-b1-ii.sql) e [03-04-b1-iii.sql](../lab/dbt_/models/chap-03/03-04/03-04-b1-iii.sql)). Note que, por causa das restrições de chave estrangeira `carro_fk` para `seguro.carro` em `seguro.possui` e `seguro.participou`, caso um registro de carro seja deletado os registros de pessoas que o possuem e os registros de acientes envolvendo esse carro também serão deletados.

```sql
select count(*) from seguro.carro; -- 4
select count(*) from seguro.possui; -- 4
select count(*) from seguro.participou; -- 7
```

Precisamos obter o ID dos carros que o motorista com o id `12345` possui. Em seguida, deletamos todos os carros de 2010 inclusos nesse conjunto. Podemos realizar essa operação através da seguinte consulta ([**!**][03-04-b2](../lab/dbt_/macros/chap-03/03-04/03-04-b2.sql)):

```sql
delete from seguro.carro ca
where ca.ano = '2010' and ca.renavam in (
  select po.renavam
  from seguro.possui po
  where po.id_motorista = '12345'
);
```

Execute as primeiras consultas novamente  (veja [03-04-b3-i.sql](../lab/dbt_/models/chap-03/03-04/03-04-b-i.sql), [03-04-b3-ii.sql](../lab/dbt_/models/chap-03/03-04/03-04-b-ii.sql) e [03-04-b3-iii.sql](../lab/dbt_/models/chap-03/03-04/03-04-b-iii.sql)) para verificar os efeitos da consulta anterior.

```sql
select count(*) from seguro.carro; -- 3
select count(*) from seguro.possui; -- 3
select count(*) from seguro.participou; -- 6
```
