Considere o banco de dados de agência bancária da Figura 3.18, em que as chaves primárias estão sublinhadas, em que as chaves primárias estão sublinhadas. construa as seguintes consultas SQL para esse banco de dados relacional.

<pre>
    agência(<u>nome_agência</u>, cidade_agência, ativos)
    cliente(<u>ID</u>, nome_cliente, endereço_cliente, cidade_cliente)
    empréstimo(<u>número_empréstimo</u>, <u>nome_agência</u>, valor)
    tomador(<u>ID</u>, <u>número_empréstimo</u>)
    conta(<u>número_conta</u>, <u>nome_agência</u>, saldo)
    depositante(<u>ID</u>, <u>número_conta</u>)
</pre>

**Figura 3.18** - Banco de dados da agência bancária.

**a)** Ache todos os clientes do banco que possuem uma conta, mas não um empréstimo.

**b)** Ache os nomes de todos os clientes que moram na mesma rua e na mesma cidade do cliente '12345'.

**c)** Ache os nomes de todas as agências com clientes que têm uma conta no banco e que moram em "Caruaru".

## Resposta

**a)**

```
select
  id
from agencia_bancaria.cliente
where id not in (
  select
    id
  from agencia_bancaria.emprestimo e
  join agencia_bancaria.tomador t
    on t.numero_emprestimo = e.numero_emprestimo
)
```

| ----- |
| 20001 |
| 12344 |
| 12345 |

**b)**

```
with cte as (
  select
    cidade_cliente,
    endereco_cliente
  from agencia_bancaria.cliente c1
  where c1.id = '12345'
) select
    nome_cliente
  from cte, agencia_bancaria.cliente as c2
  where cte.cidade_cliente = c2.cidade_cliente
    and cte.endereco_cliente = c2.endereco_cliente;
```

| nome_cliente |
| ------------ |
| Judas        |
| Beto         |


**c)**

```
with cte as (
  select id
  from agencia_bancaria.cliente
  where lower(cidade_cliente) like 'caruaru'
) select distinct a.nome_agencia
    from agencia_bancaria.agencia a
    join agencia_bancaria.conta co
      on a.nome_agencia = co.nome_agencia
    join agencia_bancaria.depositante d
      on co.numero_conta = d.numero_conta
    where d.id in (
      select id
      from cte
    )
```
