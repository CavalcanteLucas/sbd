# 03-05

Suponha que tenhamos uma relação <em>lançamentos(ID, pontuação)</em> e queiramos atribuir notas aos alunos com base na pontuação da seguinte forma: nota $F$ se <em>pontuação</em> $\lt 40$, nota $C$ se $40 \le$ <em>pontuação</em> $\lt 60$, nota $B$ se $60 \le$ <em>pontuação</em> $\lt 80$ e nota $A$ se $80 \le$ <em>pontuação</em>. Escreva as consultas SQL que fazem o seguinte:

**a)** Exiba a nota para cada aluno, com base na relação <em>lançamentos</em>.

**b)** Ache o número de alunos com cada nota.

### a)

Podemos exibir esse resultado com a seguinte consulta ([03-04-05-a](/lab/dbt_/models/chap-03/03-05/03-05-a.sql)):

```sql
select
  id,
  pontuacao,
  case
    when pontuacao >= 80 then 'A'
    when pontuacao >= 60 then 'B'
    when pontuacao >= 40 then 'C'
    else 'F'
  end as nota
from lancamentos;
```

### b)

Vamos criar uma *view* para a consulta anterior, assim podemos reutilizá-la mais facilmente ([03-05-b1.sql](/lab/dbt_/macros/chap-03/03-05/03-05-b1.sql)):

```sql
create or replace view
  notas as
select
  id,
  pontuacao,
  case
    when pontuacao >= 80 then 'A'
    when pontuacao >= 60 then 'B'
    when pontuacao >= 40 then 'C'
    else 'F'
  end as nota
from
  lancamentos;
```

Para encontrar o resultado da questão, podemos agrupar os resultados da view `notas` por nota, e contar o número de items por grupo ([03-05-b2.sql](/lab/dbt_/models/chap-03/03-05/03-05-b2.sql)).

```sql
select
  count(id),
  nota
from notas
group by nota;
```
| count | nota |
| ----- | ---- |
| 4     | B    |
| 4     | C    |
| 8     | F    |
| 6     | A    |
