### a)

Uma solução possível é ([03-08-a1.sql](/lab/dbt_/models/chap-03/03-08/03-08-a1.sql)):

```sql
select
  id
from
  agencia_bancaria.cliente
where
  id not in (
    select
      id
    from
      agencia_bancaria.tomador t
  );
```
| id    |
| ----- |
| 20001 |
| 12344 |
| 20002 |
| 12345 |

Note que, internamente, uma clásula como

```sql
coluna_externa not in (coluna_interna)
```

equivale a um conjunto de cláusulas como

```sql
    item_externo_1 <> item_interno_1
and item_externo_1 <> item_interno_2
and item_externo_2 <> item_interno_1
and item_externo_2 <> item_interno_2
...
```

para cada valor de `coluna_externa` e para cada valor de `coluna_interna`.

Sendo assim, é importante garantir que a consulta interna não retorne `NULL`. Pois o resultado de qualquer comparação com `NULL` resulta em `UNKOWN`, o que faz com que a linha seja ignorada na cláusula externa `WHERE`. Ou seja, nenhuma linha poderia satisfazer o predicado `id <> NULL`, e o resultado da consulta externa seria vazio.

Aqui, garantimos que a nenhum `id` seja `NULL` fazendo com que esse atributo seja parte da chave primária da relação:

```sql
create table agencia_bancaria.tomador (
  id varchar(10),
  numero_emprestimo varchar(10),
  primary key (id, numero_emprestimo), -- <<< chave primária
  foreign key (id) references agencia_bancaria.cliente (id),
  foreign key (numero_emprestimo) references agencia_bancaria.emprestimo (numero_emprestimo)
);
```

Uma consulta alternativa, que não incorre nessa condição, é ([03-08-a2.sql](/lab/dbt_/models/chap-03/03-08/03-08-a2.sql)):

```sql
select
  id
from
  agencia_bancaria.cliente
except
(
  select
    id
  from
    agencia_bancaria.tomador
);
```
| id    |
| ----- |
| 12344 |
| 20002 |
| 20001 |
| 12345 |

### b)

Uma solução possível é ([03-08-b.sql](/lab/dbt_/models/chap-03/03-08/03-08-b.sql)):

```sql
select
  c2.nome_cliente
from
  agencia_bancaria.cliente as c1,
  agencia_bancaria.cliente as c2
where
  (
    c1.id = '12345'
    and c1.cidade_cliente = c2.cidade_cliente
    and c1.endereco_cliente = c2.endereco_cliente
  );
```

| ------------ |
| Judas        |
| Beto         |


### c)

Uma solução possível ([03-08-c.sql](/lab/dbt_/models/chap-03/03-08/03-08-c.sql))é:

```sql
select distinct
  co.nome_agencia
from
  agencia_bancaria.conta as co,
  agencia_bancaria.depositante as d,
  agencia_bancaria.cliente as cl
where
  (
    co.numero_conta = d.numero_conta
    and d.id = cl.id
    and lower(cl.cidade_cliente) like 'caruaru'
  );
```
