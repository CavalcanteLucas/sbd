# 03-01

Escreva as seguintes consultas em SQL usando o esquema da universidade.

**a)** Achar todos os títulos dos cursos no departamento Comp. Sci. que possuem três créditos.

**b)** Achar as IDs de todos os alunos que foram lecionados por um instrutor chamado Einstein; cuide para que não haja duplicadas no resultado.

**c)** Achar o salário mais alto de qualquer instrutor.

**d)** Achar todos os instrutores que ganham o salário mais alto (pode haver mais de um com o mesmo salário).

**e)** Achar a [quantidade de] matrícula[s] de cada seção que foi oferecida no outono de 2017.

**f)** Achar o número máximo de matriculados, por todas as seções, no outono de 2017.

**g)** Achar as seções que tiveram o número máximo de matriculados no outono de 2017.

## Resposta

Os resultados apresentados a seguir consideram os dados de amostragem fornecidos no *Apêndice A* (`lab/smallRelationsInsertFile.sql`).

### a)

```sql 03-01-a.sql
select
    title
from
    course
where
    (
        credits = 3
        and dept_name = 'Comp. Sci.'
    );
```
| title                    |
| ------------------------ |
| Robotics                 |
| Image Processing         |
| Database System Concepts |

### b)

```sql 03-01-b.sql
select distinct
    ta.id
from
    takes as ta,
    teaches as te,
    instructor i
where
    (
        ta.course_id = te.course_id
        and ta.sec_id = te.sec_id
        and ta.semester = te.semester
        and te.id = i.id
        and i.name like 'Einstein'
    );
```
| id    |
| ----- |
| 44553 |

### c)

```sql 03-01-c.sql
select
    max(salary)
from
    instructor;
```
| max      |
| -------- |
| 95000.00 |

### d)

```sql 03-01-d.sql
select
  id,
  name,
  salary
from
  instructor
where
  salary = (
    select
      max(salary)
    from
      instructor
  );
```
| id    | name     | salary   |
| ----- | -------- | -------- |
| 22222 | Einstein | 95000.00 |

### e)

Uma maneira de escrever essa consulta é:

```sql 03-01-e1.sql
select
  t.course_id,
  t.sec_id,
  count(id) as takers
from
  takes as t, section as s
where
  t.semester = 'Fall'
  and t.year = '2017'
  and t.sec_id = s.sec_id
  and t.semester = s.semester
  and t.year = s.year
  and t.course_id = s.course_id
group by
  t.course_id,
  t.sec_id
order by
  takers desc;
```
| course_id | sec_id | takers |
| --------- | ------ | ------ |
| CS-101    | 1      | 6      |
| CS-347    | 1      | 2      |
| PHY-101   | 1      | 1      |

No entanto, se uma seção não possui alunos cadastrados, ela não apareceria no resultado. Para observar esse fenômeno, insira um novo registro na tabela `section`.

```sql 03-01-e0.sql
insert into
  section
values
  ('BIO-101', 2, 'Fall', 2017, 'Painter', 514, 'B');
```

Agora, execute novamente a primeira consulta [`03-01-e1.sql`] para verificar que o resultado é o mesmo.

Caso queira exibir seções com 0 alunos, como a que acabou de incluir, realize a seguinte consulta:

```sql 03-01-e2.sql
select
  s.course_id,
  s.sec_id,
  (
    select count(*)
    from takes t
    where t.course_id = s.course_id
      and t.semester = s.semester
      and t.year = s.year
      and t.sec_id = s.sec_id
  ) as takers
from section s
where (
  semester = 'Fall'
  and year = '2017'
);
```
| course_id | sec_id | takers |
| --------- | ------ | ------ |
| BIO-101   | 2      | 0      |
| CS-101    | 1      | 6      |
| CS-347    | 1      | 2      |
| PHY-101   | 1      | 1      |

### f)

Assumindo que todo registro de `takes` referencia uma registro válido de `section`, podemos escrever essa consulta de forma simplificada como:

```sql 03-01-f1.sql
select
  max(takers)
from
  (
    select
      t.course_id,
      t.sec_id,
      count(id) as takers
    from
      takes t
    where
      (
        t.semester = 'Fall'
        and t.year = '2017'
      )
    group by
      t.course_id,
      t.sec_id
  );
```
| max |
| --- |
| 6   |

Podemos verificar que esse é o caso observando a restrição de referência estrangeira utilizada para construir a tabela `takes` (`lab/DDL.sql`):

```sql lab/DDL.sql
create table
	takes (
		...
		foreign key (course_id, sec_id, semester, year) references section (course_id, sec_id, semester, year) ..., -- <<<
		...
	);
```

Caso essa restrição não seja atendida, podemos escrever uma consulta mais estrita da seguinte forma:

```sql 03-01-f2.sql
select
  max(takers)
from
  (
    select
      t.course_id,
      t.sec_id,
      count(id) as takers
    from
      takes t, section s
    where
      (
        t.semester = 'Fall'
        and t.year = '2017'
        and t.sec_id = s.sec_id
        and t.semester = s.semester
        and t.year = s.year
        and t.course_id = s.course_id
      )
    group by
      t.course_id,
      t.sec_id
  );
```
| max |
| --- |
| 6   |

### g)

De forma similar ao item anterior, podemos assumir que todo registro de `takes` aponta para um registro válido de `section` para formular a seguinte consulta simplificada:

```sql 03-01-g1.sql
with
  enrollment (course_id, sec_id, takers) as (
    select
      t.course_id,
      t.sec_id,
      count(id) as takers
    from
      takes t
    where
      (
        semester = 'Fall'
        and year = '2017'
      )
    group by
      t.course_id,
      t.sec_id
  )
select
  e.course_id,
  e.sec_id
from
  enrollment e
where
  takers = (
    select
      max(takers)
    from
      enrollment
  );
```
| course_id | sec_id |
| --------- | ------ |
| CS-101    | 1      |

  )
select
  e.course_id,
  e.sec_id
from
  enrollment e

  takers = (

  );
