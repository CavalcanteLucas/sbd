# 03-01

Escreva as seguintes consultas em SQL usando o esquema da universidade.

**a)** Achar todos os títulos dos cursos no departamento Comp. Sci. que possuem três créditos.

**b)** Achar as IDs de todos os alunos que foram lecionados por um instrutor chamado Einstein; cuide para que não haja duplicadas no resultado.

**c)** Achar o salário mais alto de qualquer instrutor.

**d)** Achar todos os instrutores que ganham o salário mais alto (pode haver mais de um com o mesmo salário).

**e)** Achar a [quantidade de] matrícula[s] de cada seção que foi oferecida no outono de 2017.

**f)** Achar o número máximo de matriculados, por todas as seções, no outono de 2017.

**g)** Achar as seções que tiveram o número máximo de matriculados no outono de 2017.

## Resposta

### a)

```sql 03-01-a.sql
select title
 from course
where credits=3;
```

### b)

```sql 03-01-b.sql
select
  distinct s.id
from student as s, takes as ta, teaches as te, instructor i
where (
  s.id = ta.id
  and ta.course_id = te.course_id
  and ta.sec_id = te.sec_id
  and ta.semester = te.semester
  and i.name like 'Einstein'
)
```

| id    |
| ----- |
| 44553 |

### c)

```sql 03-01-c.sql
select max(salary)
```

### d)

```sql 03-01-d.sql
select id, name, salary
from instructor
where salary = (
  select max(salary)
  from instructor
)
```

| id    | name     | salary   |
| ----- | -------- | -------- |
| 22222 | Einstein | 95000.00 |

### e)

```sql 03-01-e1.sql
select
  t.course_id,
  t.sec_id,
  count(id) as takers
from takes t
where semester = 'Fall' and year = '2017'
group by course_id, t.sec_id
order by takers desc
```

Alternativamente:
```sql 03-01-e2.sql
select
  s.course_id,
  s.sec_id,
  (
    select count(*)
    from takes t
    where t.course_id = s.course_id
      and t.semester = s.semester
      and t.year = s.year
      and t.sec_id = s.sec_id
  ) as takers
from section s
where (
  semester = 'Fall'
  and year = '2017'
)
```

| course_id | sec_id | takers |
| --------- | ------ | ------ |
| CS-101    | 1      | 6      |
| CS-347    | 1      | 2      |
| PHY-101   | 1      | 1      |

### f)

```sql 03-01-f.sql
select
  max(takers)
from (
  select
    t.course_id,
    t.sec_id,
    count(id) as takers
  from takes t
  where (
    semester = 'Fall'
    and year = '2017'
  )
  group by course_id, t.sec_id
)
```

| max |
| --- |
| 6   |

### g)

```sql 03-01-g.sql
with enrollment(course_id, sec_id, takers) as (
  select
    t.course_id,
    t.sec_id,
    count(id) as takers
  from takes t
  where (
    semester = 'Fall'
    and year = '2017'
  )
  group by course_id, t.sec_id
)
select
  e.course_id,
  e.sec_id
from enrollment e
where takers = (select max(takers) from enrollment)
```

| course_id | sec_id |
| --------- | ------ |
| CS-101    | 1      |
