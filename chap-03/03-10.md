**b)** Dê a todos os gerentes da "First Bank Corporation" um aumento de 10%, a menos que o salário se torne maior que $100.000; nesses casos, considere apenas um aumento de 5%.

## Resposta

Atenção: as consultas de **atualização** necessárias para reponder essas questões modificam o estado do banco. Por isso, é importante verificar o estado dos dados antes de executar as consultas a seguir.

Para preparar a tabela de lançamentos, utilize as instruçoẽs da consulta ([03-09-0.sql](/lab/dbt_/macros/chap-03/03-09/03-09-0.sql)). Em seguida, utilize a seguinte consulta ([03-10-0.sql](/lab/dbt_/macros/chap-03/03-10/03-10-0.sql)) para popular a tabela `gerencia`:

### a)

Vejamos qual a cidade desse empregado antes da atualização ([03-10-a1.sql](/lab/dbt_/models/chap-03/03-10/03-10-a1.sql)):

```sql
select
    cidade
from
    empregado.empregado
where
    id like '12345';
```
| cidade  |
| ------- |
| Belo Jardim |

Agora, vamos realizar a atualização ([03-10-a2.sql](/lab/dbt_/macros/chap-03/03-10/03-10-a2.sql)):

```sql
update empregado.empregado
set
    cidade = 'Newtown'
where
    id = '12345';
```

Execute a primeira consulta novamente para verificar a cidade desse empregado após a atualização ([03-10-a3.sql](/lab/dbt_/models/chap-03/03-10/03-10-a3.sql)):

```sql
select
    cidade
from
    empregado.empregado
where
    id like '12345';
```
| cidade  |
| ------- |
| Newtown |

### b)

Vejamos o salário dos gerentes dessa empresa antes da atualização ([03-10-b1.sql](/lab/dbt_/models/chap-03/03-10/03-10-b1.sql)):

```sql
select distinct
    g.id_gerente,
    t.salario
from
    empregado.gerencia g,
    empregado.trabalha t
where
    g.id_gerente = t.id
    and lower(t.nome_empresa) like '%first bank%';
```
| id_gerente | salario  |
| ---------- | -------- |
| 12345      | 9000.00  |
| 39991      | 11200.00 |
| 39993      | 9400.00  |

Agora, vamos realizar a atualização ([03-10-b2.sql](/lab/dbt_/macros/chap-03/03-10/03-10-b2.sql)):

```sql
update empregado.trabalha
set
    salario = case
        when salario * 1.1 > 10000 then salario * 1.03
        else salario * 1.1
    end
where
    lower(nome_empresa) like '%first bank%'
    and id in (
        select distinct
            id_gerente
        from
            empregado.gerencia
    );
```

Execute a primeira consulta novamente para verificar o novo salário desses gerentes ([03-10-b3.sql](/lab/dbt_/models/chap-03/03-10/03-10-b3.sql)):

```sql
select distinct
    g.id_gerente,
    t.salario
from
    empregado.gerencia g,
    empregado.trabalha t
where
    g.id_gerente = t.id
    and lower(t.nome_empresa) like '%first bank%';
```
| id_gerente | salario  |
| ---------- | -------- |
| 12345      | 9900.00  |
| 39991      | 11536.00 |
| 39993      | 9682.00  |

Nesse exemplo, apenas o gerente com id '12345' ganhou um aumento de 10%. Todos os demais ganharam 3%, incluindo o trabalhador com id '39993', que ficaria com um salário superior a $10.000. Qualquer outro gerente já ganhava mais de $10.000 mesmo antes do aumento.]
