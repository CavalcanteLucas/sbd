# 03-07

Considere a consulta SQL

<pre>
    <b>select</b> p.a1
    <b>from</b> p, r1, r2
    <b>where</b> p.a1 = r1.a1 <b>or</b> p.a1 = r2.a1
</pre>

Sob quais condições essa consulta seleciona valores de $p.a1$ que estão em $r1$ ou em $r2$? Examine, cuidadosamente, os casos em que ou $r1$ ou $r2$ pode ser vazio.

## Resposta

Essa consulta equivale ao produto cartesiano $p \times r1 \times r2$. Sendo assim, caso $r2$ (ou em $r1$) seja vazio, o resultado seria $p \times r1 \times \varnothing = \varnothing$. 

Vejamos um exemplo em que $r2$ é vazio para o atributo $a1$. Considere a estrutura criada em `03-07.sql`.

```
misc.p   misc.r1  misc.r2

| a1 |   | a1 |   | a1 |
| -- |   | -- |     --
| 1  |   | 1  |
| 2  |   | 2  |
| 3  |
| 4  |
```

Nesse caso, a consulta a seguir resultaria em um conjunto vazio.

```
SELECT misc.p.a1
FROM misc.p, misc.r1, misc.r2
WHERE misc.p.a1 = misc.r1.a1 OR misc.p.a1 = misc.r2.a1;
```

Agora, vamos inserir os seguintes valores em $r2$:
```
insert into misc.r2 values
  (2),
  (3);
```

Assim, teremos:
```
misc.p   misc.r1  misc.r2

| a1 |   | a1 |   | a1 |
| -- |   | -- |     --
| 1  |   | 1  |   | 2  |
| 2  |   | 2  |   | 3  |
| 3  |
| 4  |
```

Nessas condições, a consulta original resultaria no seguinte resultado:

```
| a1 |
| -- |
| 1  |
| 1  |
| 2  |
| 2  |
| 2  |
| 3  |
| 3  |
```

Note a presença de registros duplicados, já que cada valor existente nas tabelas de entrada é reproduzido na tabela de saída.
