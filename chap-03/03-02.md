# 03-02

Suponha que você tenha recebido uma relação <em><b>nota_pontos(<u>nota</u>, pontos)</b></em>, que oferece uma conversão de notas com letras na relação <em><b>realiza</b></em> para notas numéricas; por exemplo, uma nota "A" poderia ser especificada para corresponder a 4 pontos, um "A-" para 3,7 pontos, "B+" para 3,3 pontos, "B" para 3 pontos e assim por diante. Os pontos da nota obtidos por um aluno para uma oferta de curso (seção) são definidos como o número de créditos para o curso multiplicado pelos pontos nuḿericos para a nota que o aluno recebeu.

Dada essa relação e nosso esquema de universidade, escreve cada uma das seguintes consultas em SQL. Você pode considerar, para simplificar, que nenhuma tupla <em><b>realiza</b></em> tem o valor $null$ para <em><b>nota</b></em>.

**a)** Ache os pontos totais recebidos pelo aluno com ID '12345', por todos os cursos realizados por ele.

**c)** Ache a ID e a média de pontos de cada aluno.

**d)** Agora considere suas respostas dos items anteriores deste exercício supondo que algumas notas possam ser nulas. Explique se as suas soluções ainda funcionam e, se não, ofereça versões que tratem corretamente dos nulos.

## Resposta

Inicialmente, preparamos a tabela `nota_pontos` ([03-02-0-nota_pontos.sql](../lab/dbt_/macros/chap-03/03-02/03-02-0.sql)).

```sql
create table nota_pontos (
    grade varchar(2) primary key,
    points decimal(3, 2)
);

insert into nota_pontos (grade, points)
values
    ('A', 4.0),
    ('A-', 3.7),
    ('B+', 3.3),
    ('B', 3.0),
    ('B-', 2.7),
    ('C+', 2.3),
    ('C', 2.0),
    ('C-', 1.7),
    ('D', 1.3),
    ('D-', 1.0),
    ('E', 0.7),
    ('E-', 0.3),
    ('F', 0.0);
```

### a)

Podemos responder essa questão utilizando a seguinte cosulta ([03-02-a1.sql](../lab/dbt_/models/chap-03/03-02/03-02-a1.sql)):

```sql
select
  sum(n.points * c.credits) as creditos
from
  takes as t,
  nota_pontos as n,
  course as c
where (
  t.grade = n.grade
  and t.course_id = c.course_id
  and t.id = '12345'
)
```
| creditos |
| -------- |
| 48.00    |

Contudo é importante observar que, caso um estudante não tenha realizado nenhum curso, espera-se que o resultado da consulta seja 0. No entanto, a solução acima retorna `NULL`. Para verificar isso, execute a mesma consulta, dessa vez para o aluno com ID `70557` ([03-02-a2.sql](../lab/dbt_/models/chap-03/03-02/03-02-a2.sql)).

```sql
select
    sum(n.points * c.credits) as creditos
from
    takes as t,
    nota_pontos as n,
    course as c
where
    (
        t.grade = n.grade
        and t.course_id = c.course_id
        and t.id = '70557'
    );
```
| creditos |
| -------- |
|    Ø     |

Uma maneira simples de ajustar essa consulta é utilizar a cláusula `COALESCE`, apresentada no Capítulo 4, como na consulta a seguir ([03-02-a3.sql](../lab/dbt_/models/chap-03/03-02/03-02-a3.sql)):

```sql
select
    coalesce(sum(n.points * c.credits),0) as creditos
from
    takes as t,
    nota_pontos as n,
    course as c
where
    (
        t.grade = n.grade
        and t.course_id = c.course_id
        and t.id = '70557'
    );
```
| creditos |
| -------- |
| 0        |


### b)

Podemos responder essa questão utilizando a seguinte cosulta ([03-02-b1.sql](../lab/dbt_/models/chap-03/03-02/03-02-b1.sql)):

```sql
select
    coalesce(sum(n.points * c.credits) / sum(c.credits)) as media
from
    takes as t,
    nota_pontos as n,
    course as c
where
    (
        n.grade = t.grade
        and c.course_id = t.course_id
        and t.id = '12345'
    );
```
| media              |
| ------------------ |
| 3.4285714285714286 |

Utilizando a consulta acima e modificando os valores de ID, verifique que, para os casos:

- em que o estudante não existe (`id = 00000` - [03-02-b2.sql](../lab/dbt_/models/chap-03/03-02/03-02-b2.sql)),

- e em que o estudante não realizou nenhum curso (`id = 70557` - [03-02-b3.sql](../lab/dbt_/models/chap-03/03-02/03-02-b3.sql)),

que o resultado é 0.

Para o caso em que o estudante não possui nota para algum curso que realizou (`id = 98988` - [03-02-b4.sql](../lab/dbt_/models/chap-03/03-02/03-02-b4.sql)), note que essa nota não é considerada para o cálculo da média.

### c)

Podemos tentar responder essa questão utilizando a seguinte consulta ([03-02-c1.sql](../lab/dbt_/models/chap-03/03-02/03-02-c1.sql)):

    coalesce(sum(n.points * c.credits) / sum(c.credits), 0) as media

No entanto, note que alunos que ainda não realizaram nenhum curso não são apresentados no resultado. Para incluir esses casos, podemos modificar a consulta acima da seguinte maneira ([03-02-c2.sql](../lab/dbt_/models/chap-03/03-02/03-02-c2.sql)):

```sql
select
    t.id,
    coalesce(sum(n.points * c.credits) / sum(c.credits), 0) as media
from
    takes as t,
    nota_pontos as n,
    course as c
where
    (
        n.grade = t.grade
        and c.course_id = t.course_id
    )
group by
    t.id
union
select id, 0
  from student s
  where not exists (
    select 1
    from takes t
    where t.id = s.id
  )
```

### d)

Em todas as soluções acima há uma comparação entre as notas (*grade*) em `take` e em `nota_pontos`, para filtrar as linhas que devem ser consideradas na geração do resultado. Portanto, caso uma nota seja nula ela não seria incluída no cálculo. Sendo assim, nem a soma nem a média seriam afetadas nesses casos.
